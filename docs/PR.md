# MVP-каркас «Раскраски с Рыжиком»

Ветка `feature/mvp-skeleton`. Дизайн-документ — [docs/design.md](design.md).

## Что сделано

**Навигация.** Hash-роутер без библиотек (`src/router.ts`), работает под base path
`/ryzhik-coloring/`: `#/`, `#/albums`, `#/album/:id`, `#/picture/:id`, `#/reward/:id`,
`#/drawings`, `#/sound`, `#/gate/:next`, `#/parent`.

**Экраны** (`src/screens/`):

| Экран | Файл | Что есть |
|---|---|---|
| S1 Главное меню | `menu.ts` | Раскраски, Мои рисунки, Звук, счётчик звёзд, «Родителям» |
| S2 Альбомы | `albums.ts` | Карточки с точками прогресса, непопавшие альбомы помечены «скоро» |
| S3 Выбор картинки | `album.ts` | Превью реального контура, статусы начат/готов |
| S4 Раскраска | `coloring.ts` | Док 4 инструментов, палитра 14 цветов, магнит, undo/redo, Готово |
| S5 Награда | `reward.ts` | Превью рисунка, +1 звезда, две кнопки |
| S6 Мои рисунки | `drawings.ts` | Сетка, просмотр, Сохранить / Поделиться / Удалить (удержание) |
| S7 Звук | `sound.ts` | Три переключателя, состояние видно тремя способами |
| S8 Ворота | `gate.ts` | 3 попытки, кулдаун 30 с, переживает перезагрузку |
| S9 Родителям | `parent.ts` | Магнит, запирание, размер кисти, прогресс, приватность, сброс |

**S4 по документу.** Заливка по умолчанию, Кисть и Ластик с поповером размера
(8/16/26), Очистка удержанием 1.2 с с заполняющимся кольцом, палитра 14 цветов
горизонтальной прокруткой, «Магнит» чипом 64×64 на холсте (включён по умолчанию,
запирается из S9), undo/redo в топ-баре, «Готово» с порогом 85 %.

Существующая логика заливки и маски (`engine.ts`, `regions.ts`) не переписана.
В движок добавлены только новые методы: `progress()`, `exportBlob()`,
`exportDataUrl()`, `snapshot()`, `restore()`, `flush()`, хук `onPaint`;
лимит истории поднят с 10 до 30, холст центрируется по вертикали.

**Данные.** `src/data/albums.json` — альбом → список картинок. Сейчас 3 альбома,
картинка одна (`shot11`, «Рыжик и Мишка» в «Друзьях»). Ассеты подхватываются
через `import.meta.glob` по id, поэтому новая картинка = файл + строка в JSON.

**Хранение.** Настройки и прогресс — `localStorage`, черновики и рисунки
(PNG data URL) — IndexedDB (`src/platform/idb.ts`), с лимитом 200 рисунков и
без молчаливого удаления. Автосохранение каждые 3 с, при уходе с экрана и
при `visibilitychange`, без диалогов.

**PlatformAdapter** (`src/platform/`): интерфейс `storage / haptics / share /
saveImage`, веб-реализация рабочая, VK и Capacitor — заглушки с описанием
будущей интеграции. Выбор адаптера — `detectPlatform()`.

**Стиль.** Токены и шрифты из документа: Comfortaa 700 и Nunito 400/700/800
self-hosted через `@fontsource` (уже были в зависимостях), кнопки ≥ 64dp,
`prefers-reduced-motion` уважается.

## Чего нет (сознательно)

Звука и голоса (оставлены хуки `src/sound.ts` с картой событий), наклеек,
реальной интеграции VK и Capacitor, покупок, аналитики, ландшафтной раскладки
по документу (в ландшафте панель собрана компактно, но не повторяет макет с
боковым рельсом), PIN/пароля в родительском разделе, «Домика Рыжика».

## Проверка

- `npm run build` проходит (`tsc --noEmit` + `vite build`).
- Путь Меню → Альбом → Картинка → раскрасить → Готово → Награда → Мои рисунки
  пройден в headless Chromium на 360×640, 390×844, 834×1112 и 844×390:
  ошибок в консоли нет, рисунок доходит до награды и появляется в галерее.
- Отдельно проверено: раннее «Готово» (< 85 %) сохраняет рисунок, но не даёт
  звезду; короткое нажатие «Очистить» не стирает, удержание 1.5 с стирает и
  отменяется через undo; ворота блокируются на 30 с и блокировка переживает
  перезагрузку; `#/parent` без ворот перебрасывает на `#/gate/parent`.
- Геометрия: все кнопки в детской зоне ≥ 64dp, горизонтального и вертикального
  переполнения нет ни на одном из размеров. Док раскраски ограничен 520dp по ширине —
  иначе на планшете четыре инструмента растягивались до 196dp; палитра на планшете
  раскладывается в два ряда по 7 и увеличивается до 72dp.

### Как повторить

```
npm ci
npm run build
npx vite preview --port 4173 --strictPort     # или любой статический сервер под /ryzhik-coloring/
npm i -D --no-save playwright && npx playwright install chromium
SMOKE_BASE=http://127.0.0.1:4173/ryzhik-coloring/ npm run smoke
```

`scripts/smoke.mjs` проходит путь и валит проверку, если элемент меньше 64dp,
появилось переполнение, рисунок не дошёл до награды или ворота пускают без
ответа. Playwright не добавлен в зависимости проекта: он нужен только для
такой проверки.

### Ограничение, о котором стоит знать

Единственный рисунок — 16:9 (2560×1440). На телефоне в портрете холст
получается широким и низким (352×198 на 390×844). Это не баг раскладки:
панель занимает свою высоту, а лист вписывается целиком. Когда появятся
портретные рисунки, холст займёт экран. Варианты, если это мешает уже сейчас:
добавить портретные картинки или разрешить обрезку полей листа.
