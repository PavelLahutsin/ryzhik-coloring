# «Раскраска с Рыжиком» — дизайн-документ (UX/UI v1.0)

**Продукт:** детская раскраска для 3–6 лет по мультфильму «Лисёнок Рыжик»
**Платформы:** VK Mini App (первый релиз) → Android/iOS через Capacitor (общая веб-база)
**Референс:** Colour with Blippi & Friends — берём структуру, но без тяжёлого веса, IAP-воронки и англоязычности
**Готовый прототип:** раскраска с заливкой по тапу, кистью/карандашом/фломастером, ластиком, размером кисти, «не выходить за линии», undo/redo, очисткой, сохранением PNG. Документ описывает, как достроить из него полноценное приложение.

---

## 0. Как читать документ

**Единицы.** Все размеры — в `dp` (логические пиксели CSS, они же pt на iOS). Базовые макеты:
- телефон, портрет: `390 × 844`, минимум `360 × 640`;
- телефон, ландшафт: `844 × 390` (VK на десктопе и поворот экрана);
- планшет: `834 × 1112`.

**Сетка.** Шаг 8dp. Поля по бокам — 16dp на телефоне, 32dp на планшете. Safe-area учитывается отдельно (`env(safe-area-inset-*)`, в VK — собственные инсеты шапки).

**Главное правило проекта.** Ребёнок 3–6 лет **не читает**. Любое действие должно быть понятно по иконке, цвету и звуку. Текст — только подсказка для взрослого рядом.

**Размеры под детский палец (сознательно больше гайдлайновых 44–48dp):**

| Тип элемента | Размер | Зазор между соседями |
|---|---|---|
| Главная кнопка-действие | 88 × 88 | 16 |
| Инструмент в доке | 72–88 | 12–16 |
| Кружок палитры | 60–64 Ø | 10–12 |
| Второстепенная кнопка (звук, магнит) | 64 × 64 | 12 |
| Минимальный размер **где угодно** в детской зоне | 64 | 12 |

Меньше 64dp в детской зоне не делаем. Внутри кнопки — иконка 32–40dp и подпись в 1–2 слова, от 18pt Nunito 800.

**Два уровня интерфейса:**
- **Детская зона** — всё, что открывается без преград: меню, альбомы, раскраска, галерея, звук.
- **Взрослая зона** — только за «родительскими воротами»: настройки по умолчанию, покупки, внешние ссылки, шаринг, сброс прогресса, приватность.

## 1. Карта экранов и навигация

```
                      ┌──────────────┐
                      │ S0 Заставка  │ 1.2 с, только при холодном старте
                      └──────┬───────┘
                             ▼
                      ┌──────────────┐        ┌───────────────┐
              ┌───────│ S1 Главное   │───────▶│ S6 Мои рисунки│
              │       │    меню      │◀───────│   (галерея)   │
              │       └──┬────┬───┬──┘        └───────┬───────┘
              │          │    │   │                   │ тап по рисунку
              │          │    │   └──────────┐        ▼
              │          │    │              │  ┌──────────────┐
              │          │    │              │  │ S6a Просмотр │
              │          │    │              │  │  + Поделиться│→ ворота
              │          ▼    ▼              │  └──────────────┘
              │   ┌────────────┐  ┌──────────┴──┐
              │   │ S2 Альбомы │  │S7 Настройки │
              │   │ (категории)│  │  (звук)     │
              │   └─────┬──────┘  └─────────────┘
              │         ▼ тап по альбому
              │   ┌────────────┐
              │   │ S3 Картинки│  сетка превью
              │   └─────┬──────┘
              │         ▼ тап по превью
              │   ┌────────────┐
              │   │S4 Раскраска│◀── автовосстановление черновика
              │   └─────┬──────┘
              │         ▼ «Готово»
              │   ┌────────────┐
              │   │ S5 Награда │ → S1 / S3 / S6
              │   └────────────┘
              │
              │       ┌───────────────┐   ┌──────────────────┐
              └──────▶│ S8 «Родителям»│──▶│ S9 Родительский  │
                      │  (ворота)     │   │    раздел        │
                      └───────────────┘   └────────┬─────────┘
                                                   ▼ внешние ссылки
                                            (только отсюда)
```

**Правила навигации:**

1. **Не больше 3 тапов** до начала раскрашивания: Меню → Альбом → Картинка.
2. **Никакого «гамбургера» в детской зоне.** На главном всегда видны входы: Альбомы, Мои рисунки, Звук, Родителям.
3. **Кнопка «Домик»** (на S1) есть в углу каждого детского экрана: 72dp, иконка домика. Из раскраски «домой» = автосохранение и выход.
4. **«Назад»** никогда не спрашивает «Сохранить?» — всё сохраняется само. Диалог с двумя вариантами для ребёнка, который не читает, — плохое решение.
5. **Кнопка «Родителям»** нарочно неброская: 56dp, контурная, цвет `ink-soft`, 14pt, без яркой иконки, в правом верхнем углу главного экрана. Ребёнку она неинтересна, взрослому — понятна.
6. **Переходы** — сдвиг по горизонтали за 260 мс, `cubic-bezier(.34,1.4,.44,1)`. Из раскраски в награду — увеличение с проявлением за 320 мс.

| `--surface-2` | `#FBF1E2` | Вложенные панели, неактивные кнопки |

| `--orange-deep` | `#A3490D` | Нажатие на оранжевое, акценты на светлом |
| `--orange-tint` | `#FFE6D2` | Подложка активного состояния |
| `--emerald-btn` | `#157A62` | «Готово», подтверждающие кнопки |
| `--emerald` | `#1E8E71` | Иконки, позитивные маркеры |
| `--emerald-deep` | `#12654F` | Нажатие на зелёное |
| `--emerald-tint` | `#D9EFE6` | Подложка «включено» |
| `--yellow` | `#FFC94A` | Звёзды, награды, блики |
| `--yellow-tint` | `#FFF1CB` | Подложка наград |
| `--footer` | `#33291F` | Только родительский раздел (как тёмный подвал сайта) |

**Дополнительные цвета (из палитры прототипа):** `#FF4B4B`, `#FF7EB6`, `#A878FF`, `#4C8DFF`, `#63D2FF`, `#3CBF4A`, `#A56A3C`, `#2A211C`, `#FFFFFF`, `#000000`.

**Контраст.** Проверенные пары: `#3B2E25` на `#FF8A3D` ≈ 5.6:1, `#FFFFFF` на `#157A62` ≈ 5.3:1 — обе проходят AA. Любой текст в детской зоне — не меньше 18pt и не ниже 4.5:1. `ink-soft` на `bg` (#5C4A3A на #F5EDE0) ≈ 5.9:1 — подходит для подписей.

**Цвет — сигнал, но не единственный.** Активный инструмент = цвет + подъём + тень + галочка. «Магнит включён» = цвет + иконка + звук.

### 2.2 Шрифты

На сайте два шрифта с кириллицей — берём их же, чтобы приложение было из того же мира:

| Роль | Шрифт | Начертание | Размеры |
|---|---|---|---|
| Заголовки экранов | **Comfortaa** | 700 | 28 / 32 (детская зона), 20 / 26 (родительская) |
| Заголовки карточек, названия альбомов | Nunito | 800 | 20 |
| Кнопки | Nunito | 800 | 20 (детские), 16 (взрослые) |
| Основной текст | Nunito | 400 | 16 / 24 |
| Подписи, служебное | Nunito | 700 | 14 |

Правила: строка в детской зоне — **не длиннее 4 слов**, `letter-spacing: 0`, `line-height ≥ 1.35`. Comfortaa не используем для длинного текста — в мелком кегле он плохо читается. Оба шрифта подключаются подмножествами `cyrillic+latin` и хранятся локально (без Google Fonts CDN — это и приватность, и офлайн).

### 2.3 Формы, тени, иконки

- **Кнопки:** форма pill, `border-radius: 999px`, `min-height: 88` (детские) / `56` (взрослые), тень `0 14px 26px -14px rgba(233,103,26,.45)`. При нажатии — `translateY(1px)` и `scale(.97)` за 90 мс. Прямых углов в детской зоне нет.
- **Карточки:** `border-radius: 28px`, тень `0 26px 55px -34px rgba(59,46,37,.60)`, обводка `1px --line`.
- **Крупные панели и нижние шторки:** `border-radius: 40px 40px 0 0`.
- **Иконки:** собственный набор, `stroke 3`, скруглённые концы, сетка 24×24, залитые версии для активного состояния. Инструменты рисуем **как предметы**: ведро с краской, кисточка, карандаш, ластик. Ребёнок должен узнать вещь, а не разгадывать метафору.
- **Фоны:** `--bg` и едва заметный узор (листья/точки) `#A3490D` с прозрачностью 4%, ячейка 48dp, без анимации (бережём батарею и не отвлекаем). Холст раскраски всегда `#FFFFFF` — иначе ребёнок не видит границу листа.
- **Рыжик-проводник** есть на заставке, в главном меню, в награде и в подсказках. В раскраске он **не закрывает холст** — только уголок 96dp и реплики снизу.
- **Движение:** все анимации 120–320 мс, кривая с лёгким «перелётом». Учитываем `prefers-reduced-motion` — с ним остаётся только проявление за 120 мс.

## 3. Экраны

### S0. Заставка

Показывается только при холодном старте, не дольше 1.2 с. Короче — ребёнок не успеет её увидеть, дольше — начнёт тыкать в экран.

```
┌──────────────────────────────┐ 390×844
│                              │
│         ░░░░░░░░░░           │
│        ░   🦊    ░           │  Рыжик 240×240, анимация ожидания
│        ░ машет    ░          │  (моргает и один раз машет лапой)
│         ░░░░░░░░░░           │
│                              │
│      РАСКРАСКА С РЫЖИКОМ     │  Comfortaa 700, 28, --ink
│                              │
│         ● ● ●                │  индикатор загрузки — 3 точки
│                              │  (пульсируют по очереди), не спиннер
└──────────────────────────────┘
```

- Фон `--bg`. Логотип — как на сайте (Рыжик + подпись), но без навигации.
- Звука нет: автозапуск аудио до жеста пользователя запрещён. Фраза «Давай вместе!» звучит **после** первого тапа, не на заставке.
- Если ресурсы не загрузились за 3 с, всё равно открываем меню — не держим ребёнка на заглушке.

### S1. Главное меню

Четыре крупных входа. Без списков и баннеров.

```
┌──────────────────────────────┐
│                    ┌────────┐│
│   🦊 Раскраска     │Родител.││ 56, контурная, ink-soft
│   с Рыжиком        └────────┘│ отступ safe-area сверху
│                              │
│ ┌──────────────────────────┐ │
│ │                          │ │
│ │      РАСКРАСКИ           │ │ 216×160, --orange
│ │      🖍  (палитра+лист)  │ │ иконка 72, скругление 28
│ │                          │ │ → S2
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │      МОИ РИСУНКИ         │ │ 216×160, --surface
│ │      🖼  (стопка листов) │ │ обводка --line
│ └──────────────────────────┘ │  → S6
│                              │
│ ┌───────────┐ ┌───────────┐  │
│ │ 🎵 Музыка │ │ ⭐ 7      │  │ 152×112 каждая
│ │  вкл/выкл │ │ звёзды    │  │ → S7 / просто счётчик
│ └───────────┘ └───────────┘  │
│                              │
│   🦊 «Давай вместе!»         │ реплика 20pt, не кнопка
└──────────────────────────────┘
```

**Поведение и анимации:**

- При входе Рыжик выезжает слева за 320 мс, карточки появляются по очереди (`translateY(24→0)`, задержка 60 мс между ними).
- Нажатие на карточку: `scale(.97)`, звук «пуф», лёгкий отклик вибрацией. При первом нажатии на «Раскраски» за сессию Рыжик машет и говорит «Пошли!».
- Пустая галерея: карточка «Мои рисунки» выглядит неактивной, но нажимается. Открывается пустое состояние с Рыжиком и одной кнопкой «Раскрасить первый» (ведёт на S2) — не тупик.
- Счётчик звёзд — не кнопка и не вход в магазин. Магазина в детской зоне нет.
- **Ландшафт/планшет:** те же четыре карточки в один ряд, на планшете — сеткой 2×2, ширина контейнера до 720dp по центру. На телефоне основная ориентация — портрет, её можно зафиксировать (см. §5).

```
│  │  🦊👨👩👦 │  │ 🦔🐿🐰🐻 │    │ + название 20/800
```

- **Альбомы в MVP:** Семья (Рыжик, папа, мама, братик), Друзья (Ёжик, Белочка, Зайка, Мишка), Песенки (сюжетные сцены). По 8 картинок — всего 24 на старте.
- Прогресс альбома — **8 точек под обложкой**; закрашенные `--yellow` точки = раскрашенные картинки. Точки понятнее процентов и не требуют умения считать.

- **Планшет:** 3–4 колонки, карточки 200×240, отступы 32.

### S3. Выбор картинки внутри альбома

```
┌──────────────────────────────┐
│ ┌──┐  Семья             ⌂   │
│ │← │                         │
│ └──┘                         │
│  ┌─────────┐  ┌─────────┐    │ превью 156×156
│  │ ▢▢▢▢▢▢  │  │ ▢▢▢▢▢▢  │    │ чёрно-белый контур
│  │ ▢▢▢▢▢▢  │  │ ▢▢▢▢▢▢  │    │ + плашка статуса
│  │    ✓    │  │         │    │
│  └─────────┘  └─────────┘    │
│  ┌─────────┐  ┌─────────┐    │
│  │ ▢▢▢▢▢▢  │  │ ▢▢▢▢▢▢  │    │
│  │         │  │  ▶прод. │    │ ← начатый черновик
│  └─────────┘  └─────────┘    │
│                              │
└──────────────────────────────┘
```

- Превью — **всегда настоящий контур картинки** (или миниатюра раскрашенного черновика), не абстрактная иконка: ребёнок выбирает глазами.
- Статусы: чистая (без плашки) / начатая (жёлтая плашка «продолжить», иконка ▶) / готовая (зелёная галочка `--emerald`). **Готовую картинку можно раскрасить снова** — ничего не «закрывается навсегда».
- Тап — сразу S4, без вопроса «Начать?». Загрузка постепенная: сначала контур, потом всё остальное.
- Долгое нажатие (600 мс) на превью готовой картинки показывает результат крупнее (в MVP не обязательно).
- **Переход между картинками внутри раскраски** — стрелками ‹ › в нижнем углу холста, текущая картинка при этом сохраняется.

### S4. Экран раскрашивания — ядро продукта

Главная задача: **как можно больше места под холст и как можно меньше решений одновременно.** В прототипе 5 инструментов + размер + переключатель + 4 действия = 11 элементов, и трёхлетний ребёнок в них теряется.

#### 4.1 Принципы

1. **На экране — только нужные решения.** Одновременно видны: 4 инструмента, палитра одной прокручиваемой строкой (выбранный цвет выделен), отмена и повтор, выход, «Готово».
2. **Заливка по тапу — инструмент по умолчанию.** Она даёт «вау» за секунду и не требует точных движений. Кисть — второй шаг, не первый.
3. **Карандаш, кисть и фломастер из прототипа для 3-летки — одно и то же.** В MVP это **один инструмент «Кисть»** с тремя размерами. Выбор стиля (карандаш/фломастер/текстура) — внутри кисти, откладываем на v1.1. Упрощение сознательное, его легко отменить.
4. **Размер кисти не висит на экране постоянно.** Он появляется всплывающей панелью над инструментом, когда выбран рисующий инструмент. Меньше рядов — меньше промахов.
5. **«Не выходить за линии» — не переключатель в общем ряду, а «Магнит»:** отдельная кнопка-чип на холсте, **по умолчанию включена**. Ребёнку не нужно о ней думать: с ней рисунок всегда выглядит аккуратно.
6. **Очистка — не обычная кнопка, а удержание.** Обычную кнопку легко нажать случайно, а окно «Стереть рисунок? Оставить/Стереть» требует чтения, и его всё равно жмут наугад. Удержание 1.2 с с заполняющимся кругом понятно без слов и почти исключает случайность.

#### 4.2 Телефон, портрет

```
┌────────────────────────────────────┐ 390×844
│ ┌────┐  «Семья»   ┌──┐┌──┐ ┌─────┐ │ верхняя панель 88
│ │ ←  │            │↶ ││↷ │ │✓ Гот│ │ ← 72 | отмена 64 |
```

**Размер кнопок дока под ширину экрана.** При полях 16dp и зазоре 12dp:
`tool = clamp(72, (W - 32 - 3×12) / 4, 88)` → 360px → 72dp; 390px → 80dp; 430px → 84dp. Планшет — 88dp.

**Состав дока (слева направо, порядок никогда не меняется — для мышечной памяти):**

| # | Инструмент | Иконка | Поведение |
|---|---|---|---|
| 1 | **Заливка** | ведро с каплей текущего цвета | тап по области — мгновенная заливка. Выбрана по умолчанию |
| 2 | **Кисть** | кисточка | рисует текущим цветом и размером; повторный тап открывает выбор размера |
| 3 | **Ластик** | ластик | стирает и мазки, и заливку до белого; повторный тап открывает выбор размера |
| 4 | **Очистить** | лист с крестиком | **удержание 1.2 с**, вокруг кнопки заполняется круг; потом «вжух» — чистый лист, а отмена может всё вернуть |

**Палитра:** 14 цветов в одной горизонтальной строке с `scroll-snap`, кружки 60dp, зазор 10. На ширине 360px видно около 5 кружков и краешек шестого — так сразу понятно, что строку можно листать. Цвета идут по радуге, чтобы искать их по положению:
`#FF4B4B` `#FF8A3D` `#FFC94A` `#3CBF4A` `#63D2FF` `#4C8DFF` `#A878FF` `#FF7EB6` `#A56A3C` `#1E8E71` `#FFB07A` `#FFFFFF` `#2A211C` `#000000`.
У белого кружка обводка `2px --line` (иначе его не видно). Выбранный кружок — обводка `3px --ink`, `scale(1.08)` и лёгкий подъём. Текущий цвет повторяется **каплей на иконке ведра**: ребёнок видит, чем будет красить, не глядя на палитру.

**Выбор размера** — всплывающая панель над инструментом: 3 кнопки 56×56 с точками 8/16/26dp. Сама прячется через 4 с, закрывается тапом мимо.
```
        ┌─────┬─────┬─────┐
        │  ●  │ ●●  │ ●●● │
        └─────┴─────┴─────┘
              ▲ над выбранным инструментом
```

**Магнит («не выходить за линии»):** чип 64×64 в правом верхнем углу холста, фон `--surface` и тень. Включён — фон `--emerald-tint`, зелёная иконка магнита, звук «дзынь». Выключен — серый, иконка перечёркнута, Рыжик тихо «выдыхает». В родительском разделе магнит можно «запереть»: тогда на чипе замочек и он не реагирует (для трёхлеток, которым важнее аккуратный результат).

**Свободное место под холстом** на больших экранах не растягиваем: холст по центру, не больше его собственных пропорций и не больше 760×760 на планшете. Поля вокруг — `--bg` с узором, чтобы экран не выглядел «сломанным».

#### 4.5 Как работают инструменты (для разработчика)

| Аспект | Требование |
|---|---|
| Заливка по тапу | Определяем область под пальцем по карте областей. Тап мимо контура ничего не заливает, Рыжик мягко реагирует («тут пусто») — **это не ошибка**. |
| Тап у самой линии | Допуск около 2dp в сторону области: тап рядом с линией всё равно попадает в неё. |
| Кисть | Pointer Events (`pointerdown/move/up`), сглаживание, толщина 8/16/26dp, круглый конец линии. Учитываем один палец — второй игнорируем (защита от ладони на экране). |
| Магнит включён | Мазок обрезается по маске области, где он начался. Если палец выходит за линию, мазок просто обрезается — без вибрации и без звука ошибки. |
| Магнит выключен | Мазок рисуется свободно поверх всего. |
| Ластик | Стирает и мазки, и заливку (область становится белой). Размер общий с кистью. |
| Отмена/повтор | Стек на 30 шагов, работает и для заливки, и для мазков. Недоступная кнопка — с прозрачностью 40%, но **не прячется** (иначе интерфейс «прыгает»). |
| Автосохранение | Каждые 3 с и при `visibilitychange`. Черновик хранит слой краски отдельно от линий. |
| Скорость | Заливка быстрее 50 мс; мазок без рывков при 60 fps даже на 3000 точек — старые точки упрощаем. |
| Масштабирование | В MVP **нет** щипкового зума (мешает другим жестам и пугает малышей). Холст всегда вписан целиком, двойной тап по холсту отключён. |
| Выход | ← и ⌂ = сохранить и выйти. Без диалогов. |

#### 4.6 Защита от случайных нажатий

- На холсте нет «опасных» кнопок в углах, куда при хвате попадает большой палец: **правый нижний угол холста свободен**, стрелки листания утоплены и полупрозрачны.
- Между палитрой и доком зазор не меньше 16dp, чтобы тап по цвету не задел инструмент.
- Двойной тап и двойной клик ничего не делают (в Capacitor отключаем `user-scalable`, зум по двойному тапу и контекстное меню долгого нажатия).
- Реакции Рыжика **не перекрывают** док и палитру и не мешают нажатиям.
- «Очистить» — единственное действие, которое стирает всё сразу. Оно защищено удержанием 1.2 с, а отмена после очистки возвращает рисунок.

### S5. Награда за готовый рисунок

Срабатывает, когда закрашено не меньше 85% областей и ребёнок нажал «Готово». С этого момента кнопка мягко пульсирует, но рисовать не мешает.

```
┌──────────────────────────────┐
│                              │
│        ✨ конфетти ✨        │ листья и звёзды,
│                              │ 900 мс, потом стихают
│           ┌──────┐           │
│           │  🖼  │           │ мини-превью рисунка
│           └──────┘           │ 200×200, наклон -3°
│                              │
│        «Как красиво!»        │ Comfortaa 700, 28
│                              │ (голос Рыжика)
│           ⭐  +1             │ звезда летит к счётчику
│                              │ 480 мс по дуге
│   ┌──────────────────────┐   │
│   │   ЕЩЁ РИСУНОК  🖍    │   │ 88, --orange  → S3
│   └──────────────────────┘   │
│   ┌──────────────────────┐   │
│   │   В МОИ РИСУНКИ 🖼   │   │ 72, контурная → S6
│   └──────────────────────┘   │
└──────────────────────────────┘
```

- **Кнопки доступны сразу**: они не «выезжают» по таймеру и не ждут конца анимации — ребёнок не должен ждать салют.
- Ровно **1 звезда за рисунок**, без условий и без оценки «качества». Оценок нет, «плохо» не бывает.
- За каждый 5-й рисунок — **наклейка** с персонажем мира Рыжика (Ёжик, Белочка, Зайка, Мишка, папа, мама, братик). Показывается карточкой здесь же, в награде.
- Звук: короткая мелодия из 3 нот на 1.2 с, без фанфар на 5 секунд.
- Если ребёнок нажал «Готово» рано (меньше 85%), рисунок всё равно сохраняется в галерею, но награды нет: Рыжик говорит «Ещё чуть-чуть?» и возвращает на холст. Без штрафа — просто мягкая подсказка.

### S8. Родительские ворота

Открываются перед: «Родителям» (S1, S7), любой внешней ссылкой, покупкой, шарингом, сбросом прогресса, включением статистики.

```
┌──────────────────────────────┐
│                        ✕     │ закрыть → обратно в детскую зону
│                              │
│      Этот раздел для         │ Comfortaa 700, 24
│      взрослых                │
│                              │
│      Сколько будет           │ Nunito 400, 16
│      7 × 4 ?                 │ крупно, 44pt, --ink
│                              │
│  ┌────┬────┬────┐            │ клавиатура 3×4,
│  │ 1  │ 2  │ 3  │            │ кнопка 88×72,
│  ├────┼────┼────┤            │ цифра Nunito 800, 28
│  │ 4  │ 5  │ 6  │            │
│  ├────┼────┼────┤            │
│  │ 7  │ 8  │ 9  │            │
│  ├────┼────┼────┤            │
│  │ ⌫  │ 0  │ ✓  │            │
│  └────┴────┴────┘            │
│                              │
│   Неверно. Попробуйте ещё    │ после ошибки, --orange-deep
└──────────────────────────────┘
```

**Как устроена защита:**

1. Задание **каждый раз новое**, двух типов: умножение (`6×4`, `7×3`, `8×2`) и сложение двузначных (`13+9`). Подряд одно и то же не повторяется.
2. **Три попытки**, затем пауза 30 с с обратным отсчётом (кнопки неактивны). Счётчик ошибок не сбрасывается при перезапуске приложения в той же сессии.
3. Ворота — **отдельный экран на весь размер**: за ними не видно ничего из родительского раздела (никаких полупрозрачных шторок).
4. Пока открыты ворота, анимации и голос Рыжика выключены — иначе ребёнку захочется вернуться.
5. Кнопка «✕» закрывает ворота и всегда возвращает в детскую зону — приложение не запирается.
6. Ворота **обязательны на всех платформах**, включая VK. Apple (правило 5.1.4) и Google Play Families требуют родительского контроля перед выходом из приложения и покупками; модерация VK — перед внешними ссылками.
7. Доступность: задание продублировано текстом, кнопки не меньше 72dp, есть поддержка экранного диктора — но **без кнопки «прочитать задание вслух»** в самом приложении (системный диктор 4-летний ребёнок сам не включит).

**Сложность:** числа подбираются так, чтобы ответ был не меньше 20 и не решался «на автомате» 7-летним (никаких 2×2 и 5+5). Перед релизом проверяем на реальных детях.

## 4. Вовлечение без перегруза

### 4.1 Реакции Рыжика

Рыжик — **друг и комментатор**, а не судья и не надзиратель. Он никогда не оценивает и не торопит.

| Когда | Реакция | Как часто |
|---|---|---|
| Первый вход за сессию | «Давай вместе!» и машет лапой | 1 раз |
| Первая залитая область | «Ух ты!» и подпрыгивает | 1 раз за рисунок |
| Закрашено 30% | «Как красиво!» | 1 раз, не чаще раза в 90 с |
| Закрашено 70% | «Ещё чуть-чуть!» | 1 раз |
| Три тапа подряд мимо контура | Пожимает плечами, показывает на область | редко и деликатно |
| Выбран новый инструмент | Меняет позу (держит тот же инструмент) | всегда, БЕЗ звука |
| Рисунок готов | «Как красиво! Ты настоящий художник!» | всегда |
| Бездействие дольше 60 с | Ничего. **Никаких «ты тут?»** | — |

Правила: реакция **никогда не закрывает холст** — место для неё слева снизу, над палитрой. Не больше одной реплики за 90 секунд (кроме финала). Одна и та же реплика не звучит дважды подряд. Если «Голос Рыжика» выключен — только короткие звуки.

### 4.2 Звуки

| Событие | Звук | Длина |
|---|---|---|
| Тап по кнопке | мягкий «пуф» | 120 мс |
| Заливка области | «плюх», высота тона зависит от размера области | 160 мс |
| Мазок кистью | тихий шелест | повторяется, тихо |
| Тап мимо | нейтральный щелчок (не «ошибка») | 80 мс |
| Смена инструмента | щелчок повыше | 80 мс |
| Магнит включён | «дзынь» | 200 мс |
| Отмена | «плюх» наоборот | 140 мс |
| Рисунок готов | мелодия из 3 нот | 1.2 с |
| Реплики Рыжика | короткие фразы | 0.8–2 с |

**Никаких звуков проигрыша, тревожных сигналов и таймеров.** Всё аудио — мягкие ноты и перкуссия без резких атак.

### 4.3 Прогресс и наклейки

- **Звёзды** — 1 за рисунок, только счётчик на главном экране. Их нельзя потратить, ни на что не обменять, они ничего не открывают. Это просто «я молодец».
- **Наклейки** — за каждый 5-й готовый рисунок. В MVP их 12, все — персонажи и предметы мира Рыжика.
- **«Домик Рыжика»** (v1.1) — экран, где наклейки расставляются по комнатам. Это долгая цель и повод вернуться без давления.
- **Никаких серий дней.** Нет ежедневных наград и «не заходил 2 дня — серия сгорела». Для 3–6 лет это стресс, а для родителей — повод удалить приложение.
- Интерес держится **на новых картинках и альбомах**, а не на механиках удержания.

### 4.4 Сохранение прогресса

- Всё хранится на устройстве в первую очередь: черновики, галерея, звёзды, настройки. Приложение полностью работает без интернета (картинки внутри сборки).
- В VK дополнительно сохраняем компактный ключ в `VKWebAppStorage` (JSON: звёзды, наклейки, список готовых рисунков). Сами PNG — только на устройстве.
- Если устройств два, побеждает последнее сохранение. Без сложной синхронизации, рисунки не сливаются.
- Рисунок никогда не удаляется без явного действия взрослого.

## 5. Платформы

### 5.1 VK Mini App (первый релиз)

| Ограничение | Что делаем |
|---|---|
| `VKWebAppInit` | Вызываем на первом кадре, до показа контента. Обязательное требование. |
| Шапка VK и safe-area | Высота окна меняется (в веб-версии VK iframe может быть 500px). Раскладка на `dvh` и собственных CSS-переменных отступов. Верхняя панель не дублирует шапку VK, а **встаёт под неё**. |
| Клиент VK на iOS/Android | Проверяем на реальных устройствах: отступы отличаются от браузера на 10–24dp. |
| Веб-версия VK (компьютер) | Приложение открывается в узком iframe. Контейнер `max-width: 560`, по центру, фон `--bg` на всю площадь. Раскраска — с меньшим холстом и колонкой инструментов слева. Проверяем обязательно — модерация смотрит и десктоп. |
| Жесты | Свайп «назад» от левого края в iOS мешает прокрутке палитры: оставляем **24dp свободного места слева** у палитры и ограничиваем `overscroll`. |
| Внешние ссылки | Запрещены, кроме разрешённых. Все ссылки — только в родительском разделе (S9), после ворот. |
| Аудио | Только после первого жеста пользователя (иначе клиент его заблокирует). |
| Хранение | `VKWebAppStorageGet/Set` — компактное состояние. Картинки — IndexedDB, запасной вариант — `localStorage`. |
| Вибрация | `VKWebAppTapticNotificationOccurred` при заливке (лёгкая) и в награде (успех). |
| Шаринг и истории | `VKWebAppShowStoryBox` / `VKWebAppShowImages` — **только за воротами**. |
| Платежи | Только механики VK и только за воротами. В MVP платежей нет совсем. |
| Модерация | Описание без громких обещаний, скриншоты без интерфейса VK, рабочая навигация на всех трёх платформах, никаких заглушек. |

**Проверить перед релизом:** точные лимиты `VKWebAppStorageSet` и требования модерации на дату выхода — они меняются. Закладываем запас по размеру ключа, а PNG в это хранилище не кладём.

### 5.2 Capacitor (Android / iOS)

- **Одна кодовая база.** Общий слой `PlatformAdapter`: `storage.get/set`, `haptics.light/success`, `share.image`, `purchase.buy`, `files.saveToGallery`. В VK за ним стоит `vk-bridge`, в Capacitor — `@capacitor/preferences`, `@capacitor/haptics`, `@capacitor/share`, `@capacitor/filesystem`, StoreKit/Play Billing.
- **Android:** системная кнопка «назад» из раскраски сохраняет рисунок и ведёт в альбом, а не закрывает приложение; актуальный `targetSdk` по требованиям Google Play на момент релиза; без разрешения `AD_ID`.
- **iOS:** отключаем `user-scalable`, зум двойным тапом, контекстное меню долгого нажатия и всплывашки на картинках; safe-area через `env()`; **никаких сторонних SDK** (см. ниже).
- **Ориентация:** телефон — портрет (в MVP закреплён), планшет — портрет и ландшафт.
- **Размер сборки:** цель — не больше 150 МБ. Контуры картинок — SVG, а не PNG. Сборка Blippi весит 1 ГБ — этого мы избегаем.

## 6. Правила сторов и детская безопасность

### 6.1 Что делаем обязательно

1. **Никакой рекламы. Вообще.** Ни баннеров, ни «посмотри видео за альбом». Реклама — частая причина отказа в детских категориях и главный повод для родителя удалить приложение.
2. **Никакой сторонней аналитики в детской зоне.** Правило Apple 5.1.4 прямо запрещает сторонние SDK аналитики и рекламы в Kids Category и в приложениях для детей. Если статистика нужна — только своя, обобщённая, **выключенная по умолчанию**, включается в родительском разделе, без идентификаторов устройства.
3. **Родительские ворота** перед любым внешним переходом, покупкой, шарингом, сбросом данных и любым сбором данных. Этого требуют Apple 5.1.4, Google Play Families и модерация VK.
4. **Никаких внешних ссылок из детской зоны**, включая «смотрите мультфильм на YouTube». Ссылка на канал — только в родительском разделе, обычной строкой, не ярким баннером.
5. **Никаких социальных функций** для ребёнка: ни входа в аккаунт, ни чатов, ни рейтингов, ни лент.
6. **Никаких push-уведомлений** вроде «Рыжик скучает».
7. **Данные хранятся на устройстве по умолчанию**, собираем минимум. Имя ребёнка — по желанию, только для приветствия, только на устройстве.
8. **Возрастной рейтинг:** Apple — **4+**, категории Kids / Education (при заявке в Kids Category проверка строже); Google Play — рейтинг «Для всех», аудитория **Designed for Families**, соответствие COPPA и GDPR для детей.
9. **Политика конфиденциальности** обязательна: ссылка в родительском разделе и в описании в сторах. Плюс анкеты Data safety (Google) и App Privacy (Apple). «Данные не собираются» — самый простой и честный ответ, пока мы не добавляем SDK.
10. **Покупки** (если появятся): в Capacitor — только через встроенные покупки App Store / Google Play (Apple 3.1.1), в VK — только механики VK. Всегда за воротами, без таймеров и «скидки на 5 минут».

### 6.2 Что сознательно откладываем

- Аккаунты и облачную синхронизацию (нужны данные ребёнка — сложно и не нужно).
- Загрузку своих картинок (её пришлось бы модерировать).
- Совместную игру и любое общение между детьми.

**Проверка перед отправкой в стор:** пройти приложение глазами ребёнка. Если 4-летний может попасть в браузер, увидеть цену или нажать «купить» без ворот — релиз не готов.

## 7. MVP и что дальше

### MVP (VK Mini App, 6–8 недель)

| Блок | Состав |
|---|---|
| Экраны | S0, S1, S2, S3, S4, S5, S6 (базовая), S7 (звук), S8 (ворота), S9 (базовый) |
| Контент | 3 альбома × 8 картинок = 24 (Семья, Друзья, Песенки) |

| Режимы | Магнит включён по умолчанию и запирается в настройках |
| История | Отмена/повтор, 30 шагов |
| Сохранение | Автосохранение черновика, галерея, экспорт PNG |
| Вовлечение | Звуки (8 событий), 5 реплик Рыжика, 1 звезда за рисунок, счётчик звёзд |
| Родительский раздел | Звук, возраст, магнит, палитра, сброс прогресса, политика конфиденциальности |
| Приватность | Ни одного SDK, никакой рекламы, никаких сетевых запросов во время работы |
| Платформа | VK: iOS/Android/веб на компьютере, адаптация под планшет |

**Сознательно не входит в MVP:** фломастер и карандаш как отдельные инструменты, наклейки, «Домик», шаринг, ландшафт на телефоне, зум, покупки, сборки Capacitor.

### v1.1 (сборки Capacitor и доработка, 4–6 недель)

- Сборки для Android и iOS, нативная вибрация, сохранение в галерею устройства, шаринг за воротами.
- Наклейки и «Домик Рыжика», 12 наклеек.
- Режим «малыш» (3 года): только заливка, палитра крупнее, магнит заперт.
- Карандаш и фломастер как стили кисти.
- 2 новых альбома (Природа, Праздники).

### v2 (если вовлечение подтвердится)

- «Оживающие» картинки: готовый рисунок анимируется (Рыжик машет, падают листья). Сильный момент, но дорогой.
- Сезонные альбомы, озвученные истории Рыжика перед сном.
- Платные пакеты альбомов (за воротами) — или полностью бесплатная модель с одним большим альбомом.
- Ландшафт на телефоне, приближение к деталям.

### Чего не будет никогда

Таймеров, жизней, проигрышей, серий дней, рейтингов, рекламы, наград за просмотр рекламы, чатов, оценок рисунка («молодец, но можно лучше») и кнопки «Поделиться» в детской зоне.

## 8. Чек-лист для разработчика

- [ ] Все нажимаемые элементы детской зоны — не меньше 64dp, зазоры не меньше 12dp
- [ ] Ни одно действие (кроме родительского раздела) не требует умения читать
- [ ] При открытии раскраски выбрана заливка по тапу
- [ ] Магнит включён по умолчанию; чип на холсте 64×64; запирается из настроек
- [ ] «Очистить» = удержание 1.2 с с заполняющимся кругом; отмена возвращает рисунок
- [ ] Выход из раскраски = автосохранение без диалогов
- [ ] Второй палец на холсте игнорируется (защита от ладони)
- [ ] Внешние переходы, покупки и шаринг — только за воротами (пример 7×4, 3 попытки, пауза 30 с)
- [ ] В детской зоне нет сторонних SDK; статистики нет или она выключена по умолчанию
- [ ] Нет рекламы и упоминаний покупок в детской зоне
- [ ] Работает без интернета; все ресурсы внутри сборки
- [ ] Проверено на 360×640, 390×844, 844×390, 834×1112 и в веб-версии VK (iframe 560px)
- [ ] Учитывается `prefers-reduced-motion`; все анимации не длиннее 320 мс
- [ ] Контраст текста не ниже 4.5:1 во всех состояниях
- [ ] Звук не играет до первого жеста
- [ ] Шрифты Comfortaa и Nunito хранятся локально, подмножества cyrillic+latin
- [ ] PNG-экспорт не больше 1280px, лимит 200 рисунков, молча ничего не удаляется
- [ ] Родительский раздел выглядит «взрослым» (тёмные заголовки, плотная сетка)

---

**Главный компромисс документа:** из прототипа сохранено всё, что работает (заливка по тапу, «не выходить за линии», отмена/повтор, PNG). Но на экране раскраски из пяти инструментов осталось три, а два рискованных действия — очистка и выход — стали безопасными без всяких текстовых диалогов: очистка срабатывает по удержанию, выход сохраняет рисунок сам.
