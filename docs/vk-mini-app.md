# Подготовка «Раскраски с Рыжиком» к запуску как VK Mini App

Инструкция для текущей сборки проекта. Публичная версия на GitHub Pages:

**https://pavellahutsin.github.io/ryzhik-coloring/**

## 1. Создать приложение в VK

1. Откройте [первые шаги мини-приложения](https://dev.vk.com/ru/mini-apps/getting-started). На портале [dev.vk.com](https://dev.vk.com) выберите «Приложения» и создайте приложение типа «Мини-приложение». Заполните название, описание, категорию и остальные обязательные поля по подсказкам кабинета. Не указывайте неподтверждённые сведения о мультфильме, персонажах, правообладателях или команде.
2. В настройках приложения найдите поле адреса/ссылки мини-приложения и укажите HTTPS URL:
   `https://pavellahutsin.github.io/ryzhik-coloring/`
3. Сохраните настройки. Если кабинет отдельно запрашивает адреса для разных платформ или режимов показа, укажите тот же URL и проверьте требования к каждому полю в интерфейсе VK.

В проекте настроен base path `/ryzhik-coloring/`; публиковать приложение на корне домена GitHub Pages вместо указанного адреса не следует.

## 2. Проверить запуск

### Опубликованная версия

Откройте приложение из карточки/ссылки мини-приложения в VK. Именно запуск из VK добавляет параметры `vk_*` к URL, по которым приложение выбирает VK-адаптер и вызывает `VKWebAppInit`. Обычный переход на тот же сайт в браузере без этих параметров остаётся веб-версией: методы VK Bridge не вызываются.

Проверьте старт, сохранение и восстановление прогресса, а также отсутствие ошибок в консоли. Хранилище VK используется как основное, IndexedDB — как резервное. Вибрация необязательна и зависит от поддержки клиентом/устройством.

### Локальная версия

Официальные [первые шаги](https://dev.vk.com/ru/mini-apps/getting-started) предупреждают, что VK Tunnel с 2 октября 2025 года недоступен: при подключении сервис возвращает ошибку, и VK просит сторонний HTTPS-туннель либо сразу выкладку на хостинг. `vk-tunnel` поэтому не является шагом этой инструкции.

1. В корне проекта выполните `npm install`, затем `npm run dev`. Сервер слушает `127.0.0.1:5173` — так задано в `vite.config.ts`.
2. Для запуска внутри VK нужен публичный HTTPS. Откройте опубликованную страницу GitHub Pages или временно подставьте адрес своего доверенного туннеля в настройках приложения. Адрес туннеля не сохраняйте как адрес релиза.
3. Откройте мини-приложение через VK, чтобы оно загрузилось с параметрами запуска `vk_*`. После проверки верните в настройках опубликованный адрес GitHub Pages.

## 3. Подготовка детского приложения к проверке VK

Аудитория проекта по дизайн-документу — дети 3–6 лет. Перед отправкой на модерацию:

- Пройдите актуальную редакцию [правил размещения VK Mini Apps](https://dev.vk.com/ru/mini-apps-rules) и требования, которые VK показывает для конкретного приложения в кабинете. Страницы с датой в адресе (например, редакция от 20 января 2026) помечены как недействующие. Эта памятка не заменяет правила и не обещает прохождение модерации.
- Проверьте содержание и интерфейс на соответствие заявленному возрасту: понятные действия, отсутствие пугающего/неуместного материала и случайного перехода ребёнка на внешние страницы.
- Проверьте работу родительского контроля для любых действий, которые выводят контент или данные за пределы приложения (например, публикация, отправка или внешняя ссылка), если такие действия включены в релиз. Не просите у ребёнка имя, контакты, геолокацию или другие личные данные.
- Укажите в описании реальные возможности приложения и фактическую работу с данными. Приложение сохраняет состояние/прогресс через VK Storage либо IndexedDB; не заявляйте об отсутствии хранения данных. В этой интеграции не добавлены рекламные, аналитические или трекинговые SDK.
- Заранее проверьте права и разрешения на все изображения, названия и иные материалы, которые попадут в релиз. При необходимости подготовьте подтверждающие документы; не указывайте неподтверждённого правообладателя.
- Проверьте опубликованный HTTPS URL на телефоне и компьютере, поведение при первом запуске и повторном запуске, а также отображение при узком экране и безопасных отступах. Удалите из описания/интерфейса временные ссылки и тестовые сообщения.

## 4. Ограничения текущей интеграции

- VK Bridge включается только при непустом параметре запуска `vk_*` в строке запроса или в hash. Без него остаётся веб-адаптер, и `VKWebAppInit` не вызывается.
- В VK подключены `VKWebAppInit`, `VKWebAppStorageGet/Set`, вибрация (`VKWebAppTapticImpactOccurred` для лёгкого касания, `VKWebAppTapticNotificationOccurred` для успеха и предупреждения) и безопасные отступы из `VKWebAppGetConfig` / `VKWebAppUpdateInsets`. Если VK Storage не отвечает, применяется IndexedDB. Значения длиннее 4000 символов в VK Storage не отправляются.
- Публикация/шаринг рисунков через VK Bridge не реализованы: адаптер возвращает `false` для этих возможностей.
