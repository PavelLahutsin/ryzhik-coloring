# Раскраска с Рыжиком

Прототип одной раскраски: лисёнок Рыжик и медведь. Страница статическая, без сервера. Её можно открыть в браузере на телефоне или планшете, а позже обернуть в VK Mini App или приложение через Capacitor.

Рисунок лежит в двух файлах:

- `src/assets/ryzhik-i-medved.svg` — чёрные линии, ими раскрашиваем
- `src/assets/ryzhik-i-medved.png` — исходная картинка. Если svg не откроется, приложение возьмёт её

## Что нужно установить

[Node.js](https://nodejs.org) версии 20 или новее. С ним ставится `npm`.

Проверка в **cmd**:

```
node -v
npm -v
```

Должна появиться версия, например `v22.x.x`. Если команда `npm` не находится, поставьте Node.js LTS с сайта nodejs.org, закройте cmd и откройте его снова.

## Как запустить локально

В cmd перейдите в папку репозитория и выполните:

```
npm install
npm run dev
```

`npm install` скачивает библиотеки (один раз, и после обновления проекта).

`npm run dev` запускает локальный сайт. В терминале будет адрес:

```
http://localhost:5173
```

Откройте его в браузере. Остановка сервера: `Ctrl+C` в том же окне cmd.

Телефон в той же сети может открыть адрес вида `http://<IP-компьютера>:5173`, если Vite его напечатает. Для этого в `vite.config.ts` сейчас указан только `127.0.0.1` — так страница не торчит в локальную сеть. Для проверки с телефона замените `host` на `true`, перезапустите `npm run dev` и откройте Network-адрес из терминала.

## Как пользоваться

- **Заливка** — нажать на область.
- **Карандаш, кисть, фломастер** — рисовать пальцем или мышью. Размер — ползунок.
- **Не выходить за линии** — штрих остаётся в той области, где палец коснулся листа. Если выключить, рисовать можно поверх всего листа. Чёрные контуры всегда сверху, их нельзя закрасить.
- **Ластик** стирает только краску.
- **Назад / Вперёд** — отмена и повтор.
- **Очистить** — стереть краску.
- **Сохранить** — скачать PNG `raskraska-ryzhik.png`.

Шрифты и картинка входят в сборку, запросов к своему серверу нет.

## Сборка

```
npm run build
npm run preview
```

`npm run build` кладёт сайт в папку `dist`. `npm run preview` показывает уже собранную версию на `http://localhost:4173/ryzhik-coloring/` — у сборки другой базовый путь, чем у `npm run dev`.

## GitHub Pages

Файл `.github/workflows/pages.yml` публикует ветку `main` на GitHub Pages. Адрес проекта: `https://<пользователь>.github.io/ryzhik-coloring/`.

Сборка рассчитана на путь `/ryzhik-coloring/`. Локальный `npm run dev` открывается без этого префикса.

Репозиторий сейчас **закрытый**. GitHub Pages у приватного репозитория доступен не на каждом тарифе, и страница не будет видна всем. Чтобы сайт открылся публично:

1. Сделать репозиторий публичным: Settings → General → Danger Zone → Change visibility.
2. Включить Pages: Settings → Pages → Build and deployment → Source: **GitHub Actions**.
3. Запушить `main` или запустить workflow **Deploy GitHub Pages** вручную.

## Где код

| Файл | Зачем |
| --- | --- |
| `index.html` | Кнопки и подписи |
| `src/main.ts` | Связывает кнопки с холстом |
| `src/engine.ts` | Холст: краска снизу, линии сверху, отмена, сохранение |
| `src/regions.ts` | Области заливки: видимые линии, короткие мостики на концах штрихов, без ложных границ |
| `src/style.css` | Внешний вид |
| `src/screens/lullabies.ts` | Экран колыбельных и режим сна |
| `src/data/lullabies.ts`, `lullabies.json` | Список колыбельных |
| `scripts/regions.ts` | Проверка новой картинки и отчёт |

## Колыбельные

Экран «Колыбельные» (пункт меню с луной) с режимом сна: таймер 10 / 20 / 30 минут (по умолчанию 20), последняя минута затихает, затем пауза. Выбранный таймер сохраняется в настройках.

Пока колыбельных нет, экран показывает текст «Скоро здесь будут колыбельные Рыжика» без кнопок.

**Как добавить колыбельную (один шаг для файлов + одна строка в JSON):**

1. Положите mp3 в `src/assets/audio/lullabies/`, например `kolybelnaya_1.mp3`.
2. Добавьте строку в `src/data/lullabies.json`:

```json
[
  { "id": "kolybelnaya_1", "title": "Название колыбельной", "file": "kolybelnaya_1.mp3" }
]
```

Файлы подключаются через `import.meta.glob` при сборке, поэтому они работают офлайн. Строка без файла пропускается и не ломает экран. Названия пишите сами: в проекте нет готовых колыбельных и их названий.

Звук колыбельных подчиняется переключателю «Музыка» в разделе «Звук». Когда он выключен, экран подсказывает его включить и ничего не играет.

## Новая картинка

Положите контур в `src/assets/pictures/<id>.svg` (или `.png`) и строку в `src/data/albums.json`. Затем в cmd:

```
npm run regions
```

Скрипт приводит картинку к одной ширине, находит линии, закрывает короткие разрывы только на концах штрихов и убирает границу там, где между областями нет линии. Рядом с картинкой появляется `<id>.qa.json`:

- сколько областей;
- мелкие кармашки;
- ложные границы — две области соприкасаются на чистой бумаге, линии между ними нет;
- узкие протечки — одна область всё ещё соединяет две большие части коридором в несколько пикселей.

Длинный разрыв, которого нет на рисунке (например лапа и предплечье мишки — это одна фигура без линии на запястье), скрипт не дорисовывает. Такой кусок нужно поправить в исходной картинке. Одни и те же правила для всех картинок, подгонять числа под конкретный рисунок не нужно.


## Android

Для сборки нужны Node.js 20+, Android Studio с Android SDK и JDK 21. В Windows откройте `cmd` в папке проекта:

```cmd
npm install
npm run cap:sync
npm run cap:open
```

Дождитесь синхронизации Gradle в Android Studio и выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**. Либо выполните из корня проекта `cd android` и `gradlew.bat assembleDebug`. Debug APK: `android\app\build\outputs\apk\debug\app-debug.apk`. Установка на подключённый телефон с USB-отладкой: `adb install -r android\app\build\outputs\apk\debug\app-debug.apk`.

Иконка и splash сейчас временные заглушки — замените перед публикацией. Приложение работает офлайн: картинки, шрифты и звуки лежат внутри APK и открываются как `https://localhost` без сети. Разрешение INTERNET убрано, для вибрации остаётся VIBRATE. Кнопка «Назад» на раскраске сначала сохраняет рисунок, а с родительского вопроса возвращает в меню. «Сохранить» и «Поделиться» открываются только после вопроса для взрослых.
